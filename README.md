# Implementing Micro-Segmentation in a Zero Trust Network

## Overview
I designed and implemented micro‑segmentation controls to enforce Zero Trust principles. The goal was to isolate workloads, restrict unauthorized communication, and reduce the attack surface across critical systems.

## Key Features
- Granular firewall rules applied per subnet/workload.
- Deny‑by‑default policies with explicit allow rules.
- Continuous traffic monitoring and validation.
- Alignment with Zero Trust and least‑privilege principles.

## Benefits
- Prevents lateral movement by attackers.
- Protects sensitive workloads from insider threats.
- Strengthens compliance with modern security frameworks.
- Enhances resilience against ransomware and advanced persistent threats.

## Conclusion
Micro‑segmentation is a core pillar of Zero Trust security. By enforcing strict access boundaries and validating traffic continuously, this project demonstrates how organizations can achieve stronger defense‑in‑depth and safeguard critical assets.
